## 공개 화면 확인

화장품 종류는 선택 사항이며 최대 3종이다. 스킨·토너·앰플 선택 뒤 네 번째 크림을 눌렀을 때 추가되지 않고 제한 안내가 나왔다. 모델링팩은 세럼에서 앰플로 바꾸면 한 개만 남고, 다시 해제하면 종류 미선택 자동 추천 안내가 나왔다. 검사 후 공개 화면은 기본 미선택 상태로 돌려놓았다.
