## 실제 연동에서 발견한 오류와 수정

새 근거를 연결하고 실제 설명 단계를 실행하자 HTTP 400이 발생했습니다.
원격 오류는 “schema produces a constraint that has too many states for serving”였고,
중첩된 배열·문자열의 길이 제한이 큰 출력 규격에서 발생했습니다.
첫 사진 판독은 성공했고 설명 호출에서 거절됐음을 비공개 원응답 기록으로 구분했습니다.

Gemini로 보내는 생성용 Schema에서는 min/maxLength, min/maxItems, title만 제외합니다.
필드명·required·객체 구조·enum·추가 필드 금지는 유지하고,
반환된 응답은 기존 Pydantic 모델로 길이와 목록 개수를 포함해 다시 엄격히 검사합니다.
새 회귀 시험에서 2,001자 설명이 로컬 검증에 거절되는 것을 확인했습니다.

수정 후 실제 브라우저 I001 시험은 판독 1회 + 설명 1회로 성공했습니다.
성분 16개 중 자료와 일치하는 알란토인 1개만 설명하고 YSW_A001_KO 근거를 표시했습니다.
화면의 일반 기능 참고·독립 사람 교차검토 필요 안내도 확인했습니다.
400 실패와 수동 진단을 성공 건수나 정확도에 포함하지 않았습니다.
