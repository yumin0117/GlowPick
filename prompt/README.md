## 서버 연동 핵심 요약

- `01_시스템프롬프트.md`의 A 블록 → `systemInstruction`
- B·C 블록의 `{중괄호}`를 사용자 입력으로 채워서 사진과 함께 전송
- `responseMimeType: application/json` + 응답 스키마로 `02_schema_*.json` 사용 (Python SDK는 `response_json_schema`)
- `temperature` 0.2 내외
- 모델: 테스트는 `gemini-3.5-flash`로 진행함. 서버에서 다른 모델을 쓰면 알려 주세요.
