# 집컴에서 시작하기

## 1. 압축 풀고 표 확인
ZIP 전체를 한 폴더에 풀고 README를 읽습니다. data/products.csv와 data/pairs.csv는 Excel로 열 수 있습니다(UTF-8 BOM). 셀에 적힌 미확인 상태를 지우지 마세요. 이전 ZIP은 보관하고 새 패키지를 작업 기준으로 사용합니다.

## 2. 설치 없이 Colab 이용
1. Google Colab에서 파일 → 노트북 업로드 → notebooks/GlowPick_Colab_검증.ipynb 선택.
2. 런타임 → 런타임 유형 변경 → T4 GPU(무료 할당이 없으면 중단; 결제 연결하지 않음).
3. 첫 안내부터 순서대로 실행합니다. 업로드 버튼에는 이 최종 ZIP을 선택합니다.
4. 첫 점검 셀은 GPU·API 없이 비교 도구와 파일을 검사합니다.
5. 모델 설치 셀과 OCR 셀을 실행하면 HF 공개 가중치를 내려받습니다. 최초 다운로드는 수 GB가 필요할 수 있습니다. 메모리 부족이면 세션 삭제 후 다시 시작하고 한 장씩 실행하세요.
6. results/hf_runs.json에서 execution_status, 원응답, 지표를 봅니다. error와 미실행을 성공으로 계산하지 마세요. 결과 다운로드 셀로 ZIP을 집컴에 저장합니다.
7. Gemini 셀은 선택 실행입니다. Colab 열쇠 아이콘 → GEMINI_API_KEY와 GEMINI_MODEL을 비밀값으로 추가합니다. 모델은 본인 무료 계정에서 가능한 이름을 확인하여 넣습니다. 결제 계정 연결은 과제에서 금지했습니다.
8. 성분을 사람이 대조한 뒤 reviewed=True로 바꾸어 호출합니다. 개인정보와 피부 사진은 쓰지 마세요.

수업자료의 google-genai==2.12.1과 Interactions 형태를 따랐습니다. 이 환경에서 해당 버전 설치·API 호출은 시험하지 못했습니다. 설치 버전을 찾을 수 없거나 API가 바뀌면 실패 화면을 저장하고 서버 담당과 공식 문서를 대조하세요. 다른 버전으로 조용히 바꾸어 실행했다고 기록하지 마세요. Pillow 업그레이드는 하지 않습니다(5주차 주의사항).

## 3. 집컴에서 비교 화면만 열기(선택)
Python 3.10 이상 설치 후 이 폴더에서 터미널을 열어 실행합니다.
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe space/app.py
```
표시된 로컬 주소를 브라우저로 엽니다. Python 설치가 번거로우면 Colab의 Gradio 셀을 쓰세요. Space 비교 화면은 OCR이 자동으로 돌아가는 완제품이 아닙니다.

## 4. Hugging Face Space로 공유
1. 본인 계정 → New Space → Gradio → 무료 CPU 선택. 결제·GPU 업그레이드는 하지 않음.
2. 패키지의 src/evaluate.py, space/app.py, requirements.txt 및 허용된 data·images를 같은 구조로 업로드.
3. Space README의 YAML: sdk: gradio, app_file: space/app.py. 아래 예시를 사용합니다.
```yaml
---
title: GlowPick ingredient validation
sdk: gradio
app_file: space/app.py
---
```
4. Build 로그에서 설치 오류를 확인하고, 예제 JSON을 넣어 누락·추가 오류가 보이는지 시험.
5. 공개 이미지 권한이 불명확하면 개인 촬영 자료로 바꾸거나 비공개 설정에서 검토합니다.

이 Space는 저사양에서 비교·검토를 담당합니다. Qwen GPU 추론은 Colab에서 수행하고 실제 응답을 붙여 넣습니다. CPU Space에서 3B 비전모델을 무료로 빠르게 실행한다고 약속하지 않습니다. 선택적으로 Colab의 임시 Gradio 주소에서 OCR 시연을 할 수 있지만 세션 종료 시 주소가 사라집니다.

## 5. 실제 사진을 추가하는 순서
집에 있는 제품의 전성분 영역을 직접 촬영 → 제품명/시장/용량/구매시기/리뉴얼 구분 → 원문 그대로 두 번 전사 → 팀원 교차 검토 → 이미지 해시와 출처 기록 → 모델 입력 → 정답 대조 → 오류 저장.
선명한 전체 목록부터 시작하고 흐림·반사·기울기·앞면만 있는 사진을 추가합니다. 같은 제품의 변형 사진은 같은 split으로 묶어 평가 자료 유출을 막습니다. 이미지 가공본은 원본으로 세지 마세요.
