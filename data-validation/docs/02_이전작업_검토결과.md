# 이전 ZIP 검토와 재사용 결정

## 재사용
- 제품 6개 목록: 원문·제품·시장·출처를 보존. 현재 웹 재확인과 이전 확인 날짜를 분리.
- 원본 이미지 12개: 모든 SHA-256이 기존 images.json과 일치. 해시 일치는 파일 동일성을 뜻하며 출처의 현재 유효성·전사 정확도 증명이 아님.
- JS 비교 모듈·31개 단위시험: 숫자 쉼표, 괄호, slash, 누락·추가·순서·혼합 근거 검사를 재사용.
- findings: 자료 불일치 기록은 검토 계획으로 보존. C006 일정은 과제 PPT 버전 간 차이가 있어 확정 마감으로 쓰지 않음.

## 수정·제외
- 기존 보고서 PDF·XLSX와 발표 대본은 새 결과로 재배포하지 않음. 강의 적합성 및 새 실행 결과를 반영하지 않았기 때문.
- 기존 results는 evidence/previous_results로 이동하여 현재 테스트와 분리.
- image_cases의 not_run을 유지. comparison_examples의 가상 오류 예시는 실제 모델 실행으로 쓰지 않음.
- 12장을 '실제 라벨 12장'으로 세지 않음. I001/I002는 동일 모델링팩 전성분 패널, I004는 앰플 3제품 공통 표, I003/I005는 사용법·광고, 나머지는 주요 성분/앞면 등.
- P001/P002는 공식 웹 텍스트가 존재해도 포함된 앞면 사진에는 전성분 전체가 없음. 해당 사진에 웹 성분 전체를 정답으로 붙이지 않음.
- 제품 성분 기능·혼합 관련 기존 evidence/ingredients는 이전 검토 자료임. 이번 작업에서 효능이나 안전성의 독립 검증을 완료하지 않음. 추천 근거로 자동 승격 금지.

## 전성분 시각 재검토
I001, I002, I004를 원해상도로 열어 전성분 및 제품 분리를 대조했습니다. I004는 보습/영양/AC컨트롤을 각각 크롭했습니다. 결과는 임시 정답이며 독립 사람 검토가 아닙니다. 원문 줄바꿈은 공백으로 이어 붙였고, 성분 순서와 1,2-헥산다이올 및 괄호 안 쉼표를 유지했습니다. 표준명 사전과 동의어는 자동 통합하지 않았습니다.
I001에는 모델링팩인데 토너 뒤 흡수시키는 사용법이 적혀 있습니다. I003은 물과 혼합 후 떼어내라고 하므로 두 사용법이 충돌합니다. 이 표의 사용법을 사용자 추천에 전송하지 마세요.

## 확보되지 않은 자료
실물 곡면·반사·흐림·조명 조건 사진, 국문/영문 실제 라벨 10~15장, 사람 교차검토, 실제 AI 전후 개선 성능은 확보/실행하지 못했습니다. 미확인 자료를 보충 작성하지 않았습니다.
